# Scout Local 隐私说明

## 保存在本机的内容

Scout 默认把以下内容保存在 `%LOCALAPPDATA%\Scout\data`：

- 对话与任务状态；
- 抓取的公开网页正文；
- 中文译文、书架、批注和阅读记忆；
- 用户主动关注的公开来源。

Scout 不提供自己的遥测、广告或用户画像上传服务。

## 会离开本机的内容

- 搜索、筛选、翻译和问答所需的提示、网页材料或相关段落会发送给用户自己登录的 Codex，
  并受用户与 OpenAI 之间的方案、数据控制和条款约束；
- Scout 抓取公开网页时会向原网站发送普通 HTTP 请求；需要渲染时会使用本机 Chromium；
- 用户主动配置其它搜索提供商时，对应查询会发送给该提供商。

## Codex 登录

Scout 在 `%LOCALAPPDATA%\Scout\codex-home` 使用独立的 Codex 登录目录。安装器不会复制、读取或
改写用户平常使用的 `%USERPROFILE%\.codex`。用户可以停止 Scout，并在明确需要时删除这个独立
登录目录以撤销本机上的 Scout 登录状态。

## 删除与备份

程序源码与用户数据分开。更新程序不会删除数据。任何卸载步骤都必须默认保留数据；删除
`%LOCALAPPDATA%\Scout\data` 前应先由用户明确确认并按需备份。
